# AMCEC QPSet — Frontend Client

This directory contains the React 18 + Vite 5 client application for **AMCEC QPSet**.

- **Main Documentation & Setup**: Refer to the root [README.md](../README.md) for full project documentation, architecture, API specifications, and setup instructions.
- **Development Server**: `npm run dev` (starts on `http://localhost:5173`)
- **Build**: `npm run build`
- **Tests**: `npm run test` / `npx playwright test`
